# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `sqlilab`, please disclose responsibly:
- Email security reports to: `security@example.com`
- Do not disclose vulnerabilities in public issues or pull requests.
- Please include reproduction steps, sample payload vectors, and environment details.
